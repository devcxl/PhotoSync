# 08: 1024px 全图 Pre-pass 金字塔、清晰度/纹理/锐化/降噪与暗通道去雾切片（Pass C）

**What to build:** 交付 1024px 全图低清预分析（Pre-pass）与物理 Pass C（空间细节多级链）：在松手定格或导出启动前，先在 1024px 代理 FBO 上一次性求出去雾全局唯一大气光 $A$（暗通道前 0.1% 最亮像素）、粗透射率图 $t_{\text{low}}$ 以及清晰度（2% 短边）与纹理（0.3% 短边）共享的多尺度低频引导金字塔；在 Pass C 中依次执行亮度引导滤波 + 色度 CbCr 5×5 边缘引导降噪、暗通道去雾、清晰度（叠加光感联动项 `0.20 * glow`）与纹理高通限幅增强、以及仅作用于 Y 通道的边缘门控反锐化掩模（按全清像素定义半径）；当所有空间细节参数与光感均为 0 时，整个 Pass C 以 0 Draw Call 短路跳过。

**Blocked by:** 06: 显示域色彩、单调三次曲线、8 色带 OKLCH HSL 与色调分离切片（Pass B 下半段）

**Status:** ready-for-agent

- [ ] 实现 `PrepassAnalyzer`：在 1024px 代理图上提取 $256\times 256$ 暗通道前 0.1% 全局大气光 $A$、引导滤波平滑后的粗透射率 $t_{\text{low}}$，以及 512px（0.3% 短边）与 128px（2.0% 短边）两级低频亮度引导层，打包入 `uPrepassTex`。
- [ ] 实现 Pass C 降噪（亮度 $3\times 3$ 引导滤波 + `detail` 回混；色度 CbCr $5\times 5$ 可分离边缘引导平滑）与去雾（采样全局 $A$ 与 $t_{\text{low}}$，透射率下界 $\max(t, 0.1)$，$\omega \le 0.95$）。

- [ ] 验证当细节组滑杆与 `glow` 全为 0 时，Pass C 完全短路跳过（0 次 FBO Draw Call）。
