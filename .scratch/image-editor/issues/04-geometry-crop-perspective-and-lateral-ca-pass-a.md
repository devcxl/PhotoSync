# 04: 几何重采样与光学横向色散校正切片（Pass A）

**What to build:** 交付「几何」面板的旋转 90°、水平/垂直翻转、带比例锁的自由裁切、任意角度拉直（`-45°..+45°`）、四点透视校正，以及「细节/光学」中的横向色散（Lateral CA R/C 与 B/Y）校正。所有几何与光学重采样合并在物理 Pass A 中通过单次逆映射采样完成：先确保源图按 EXIF/LibRaw 一次性归一化至正向（严防二次旋转），在拉直与透视变形时自动求解最大内接无黑边矩形，并在裁切前（pre-crop）绕原图光心 `(0.5, 0.5)` 对 R/B 通道做径向缩放重采样以消除镜头横向色差。

**Blocked by:** 02: 编辑器模块骨架、非破坏性 EditGraph 持久化与首条曝光垂直切片

**Status:** ready-for-agent

- [ ] 源图方向归一化：LibRaw 保持 `user_flip = -1` 不再二次旋转；JPEG 通过 `BitmapFactory` + `ExifInterface` 一次性转正为 `Orientation = 1`（验证全部 8 种 EXIF Orientation 输入均正向显示）。
- [ ] 实现 `CropOverlayView` 与手势路由：切入裁切/拉直/透视工具时，单指拖拽四角/四边/刻度盘实时更新逆单应矩阵 $H^{-1}$，双指捏合仍可缩放平移画布底图。
- [ ] 任意角度拉直与四点透视校正自动计算并约束在最大内接有效像素矩形内，预览与导出画面四角永不出现黑边或透明空洞。
- [ ] 在 Pass A Shader 中基于 pre-crop 原始光心坐标实现 R/B 通道 `(1 + k * r²)` 横向色散径向重采样（先于裁切与后续锐化）。
- [ ] 包含 8 种 EXIF 方向归一化、内接矩形几何约束与逆单应矩阵恒等性的自动化测试。
