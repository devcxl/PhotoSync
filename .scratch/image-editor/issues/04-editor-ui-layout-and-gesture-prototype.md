# 单屏 XML/ViewBinding 编辑器交互与手势冲突原型

Type: prototype
Status: open

## Question

在不使用 Jetpack Compose、纯 XML + ViewBinding 且单文件 ≤ 500 行的硬约束下，`EditorActivity` 需要承载 6 大功能分组（几何、影调、色彩、细节、效果、人像）共 30 项能力，并同时处理多种画布与面板手势。需通过原型明确：
1. **单屏层级导航结构**：顶部栏（返回/撤销/重做/对比原图/重置/导出）、中央 `SurfaceView` 画布区、底部二级工具栏（一级分组 Tab → 二级子工具 Chip → 参数滑杆 / 曲线编辑器 / 8 色带 HSL 面板 / 3D LUT 缩略图列表）在竖屏与横屏下的布局与状态切换状态机。
2. **画布手势路由与冲突消解**：当处于不同工具态时，单指拖拽与双指缩放/平移如何路由？
   - 普通调色态：单指平移画布、双指缩放画布、长按画布对比原图；
   - 裁切/拉直/透视态：拖拽四角/四边控制点与刻度盘 vs 画布缩放；
   - 液化画笔态：单指涂抹累积位移场 vs 双指缩放平移画布（及笔刷大小/强度/擦除切换）。
3. **高频渲染节流交互**：滑杆连续拖动时（1024px 代理分辨率实时渲染 + 300ms 撤销栈事务合并）与松手后（150ms 触发全质量空间细节渲染）的视觉反馈。
4. **主界面 × 编辑器「联机暗房」交互布局**：
   - 主界面 `activity_main.xml` 增量控件布局：顶部栏 `editButton`、`photoEditedBadge`（「已编辑」胶囊）、长按大图对比原图（Before/After 提示胶囊）、可收起的底部「快捷预设栏（Quick Preset Strip）」与「联机自动套用预设（LiveTetherPreset）」开关、跨照片「复制/粘贴参数」入口及批量烘焙导出进度卡片；
   - 编辑器内顶部「RAW 基准观感（默认/线性中性）」切换开关、「保存为用户预设」入口，以及编辑期间后台 USB 新同步照片的免打扰轻提示胶囊。
