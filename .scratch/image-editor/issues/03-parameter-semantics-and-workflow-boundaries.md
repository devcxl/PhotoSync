# 开放参数语义与非破坏性编辑工作流边界

Type: grilling
Status: open

## Question

在将 30 项能力冻结为正式规范与 `EditGraph` Schema 前，需与产品/技术负责人敲定以下核心语义与工作流边界决策：
1. **「光感（Glow）」滑杆的确切语义与数学定义**：采用方案 A「通透光感」（亮部柔化 + 暗部提亮 + 清晰度联动），还是方案 B「Snapseed 氛围（Ambiance）」（大半径局部对比度 + 阴影提亮高光压暗 + 微量饱和度补偿）？
2. **「噪点（Noise）」与「颗粒（Grain）」/「降噪（NR）」的 UI 消歧**：UI 面板中是否将「降噪」（消除图像噪声）与「颗粒」（胶片感加噪）分置，并将需求列表中的「噪点」固定映射为「颗粒」或「明度/色度降噪」子项？
3. **改变几何边界操作（拉腿、透视校正、任意角度拉直）的画幅裁切策略**：导出与预览是否统一**强制内接矩形裁切回有效像素区域**（保持无黑边、不改变原图外部空白），还是允许画幅比例自由改变？
4. **非破坏性编辑对主界面浏览与导出的影响**：当一张照片存在已保存的 `EditGraph` 时：
   - 主界面大图浏览（`ViewPager2`）与底部胶片条（`FilmstripAdapter`）是展示**带编辑效果的渲染缓存图**（并带「已编辑」角标），还是仅展示原图？
   - 主界面的「导出」按钮是默认导出**应用了最新 `EditGraph` 的成片**，还是仅导出未编辑原图（必须进编辑器才能导出成片）？
5. **RAW「0 参数默认基准 Look」开关**：编辑器内是否允许用户一键在「PhotoSync 默认观感（对齐浏览页自动提亮+基础 S 曲线）」与「纯线性中性 RAW」之间切换基底？
