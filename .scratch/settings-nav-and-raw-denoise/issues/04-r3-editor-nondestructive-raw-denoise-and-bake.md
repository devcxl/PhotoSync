# 04: R3 编辑器非破坏性 RAW AI 降噪、预览对比与全分辨率烘焙

**What to build:** 在 `EditGraph` v2 中向后兼容扩展纯参数节点 `RawDenoiseOps`（包含开关、强度、可选手动 ISO 与模型标识，绝不落盘全分辨率线性像素帧），同步接入中性判定、参数校验器、JSON 编解码、重置原图、参数复制掩码与编辑器撤销合并；在编辑器 AI 工具栏新增「RAW 降噪」面板（开关、强度滑杆与自动/手动 ISO 调节；未装模型复用共享安装弹窗；JPEG 照片明确置灰并提示仅支持 RAW）。确立「解码 → RAW 降噪 → 消除补丁叠加 → 几何与调色细节效果管线」的固定顺序，保证消除补丁绝不被二次平滑：编辑器预览在预览尺寸线性帧上运行并缓存降噪基图（拖动强度滑杆实时线性混合不重跑推理，长按原图对比瞬间切回未降噪原片），支持进度条与取消；全分辨率烘焙同时覆盖整帧驻留档、半分辨率档与超高像素逐带切片档（为切片规划补齐 64 px 降噪感受野 halo，超纹理上限安全回落既有整帧降级路径）。同步更新领域词汇、三语 README、过期批量烘焙文档标注与 RAW AI 降噪架构 ADR。

**Blocked by:** 02: R1 TreeNet Light 模型分发、设置键与线性分块降噪引擎

**Status:** ready-for-agent

**Acceptance criteria:**

- [ ] `RawDenoiseOps` 完整接入 `EditGraph` v2 编解码（旧文档无损解码为中性）、中性判定、参数校验与越界 clamp、重置原图、复制掩码与撤销合并，且不落盘任何线性像素资产。
- [ ] 编辑器 AI 栏新增「RAW 降噪」工具：RAW 照片可调节开关/强度/ISO、触发未装模型安装弹窗并在运行期支持取消；JPEG 照片置灰提示且不触发推理。
- [ ] 预览单帧缓存单测锁定同图同 ISO 命中缓存、调整强度仅重混不重跑、换图或关闭即失效；烘焙顺序单测锁定先降噪后叠加消除补丁、切片规划包含 64 px 感受野 halo 且保持既有超限降级逻辑。
- [ ] 完成领域词汇增补（并清理已移除的批量烘焙词条）、过期 ADR 标注、RAW AI 降噪架构 ADR 及三语 README 更新。
