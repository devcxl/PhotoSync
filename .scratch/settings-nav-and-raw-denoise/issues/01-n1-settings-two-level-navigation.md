# 01: N1 设置页二级分类架构重构（分类列表 → 二级详情页）

**What to build:** 保留现有六个设置分类，将原本平铺在单个超长滚动页中的所有设置重构为「一级分类列表 + 二级分类详情页」两级导航。一级页仅展示六个分类入口行（图标、标题、零磁盘 I/O 的轻量动态摘要与右箭头），打开首帧不触发全盘目录扫描或模型探针；点击「云端增强」直达既有云端配置页（一级行保留只读启用状态摘要），点击其余五个 `SettingsCategory`（联机与相册、编辑器、AI 工具、存储与缓存、关于与诊断）进入非导出的二级详情页，运行时仅按需注入对应分类的视图与控制器，收窄存储与诊断模块的视图绑定范围，将 LUT 与天空素材导入启动器迁移至详情页，并统一所有分类在返回恢复时的刷新行为（补齐编辑器分类恢复重绘），消除单页视图过多与过度绘制告警。同步拆分并扩充设置页测试，记录二级导航架构 ADR。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

**Acceptance criteria:**

- [ ] 一级设置页仅呈现六个分类入口行与零磁盘 I/O 动态摘要，首帧打开不触发存储目录扫描；「云端增强」点击直达云端配置页。
- [ ] 其余五个 `SettingsCategory` 点击进入非导出的二级详情页，运行时仅注入对应单个分类布局并完整保留所有既有设置读写与子页跳转能力；所有分类在页面恢复时同步最新状态。
- [ ] LUT 与天空素材导入及五类存储清理、只读诊断在对应二级页正常工作；设置页不再触发视图过多 Lint 告警。
- [ ] 一级列表与各二级分类详情页具备完整的 Robolectric 冒烟与交互测试覆盖，并落盘对应架构 ADR。
