# 02: R1 TreeNet Light 模型分发、设置键与线性分块降噪引擎

**What to build:** 将经过实测验证的 MIT 许可线性 RAW 降噪模型 TreeNet Light（四条字节一致镜像）纳入按需 AI 模型目录，扩展目录校验脚本支持四镜像探针与校验，同步更新第三方许可声明、基线研究记录与模型管理页文案；在编辑器设置门面中新增与既有应用设置严格互斥的三个 RAW 降噪键（直出模式、高感自动门槛与降噪强度），声明默认值、合法范围 clamp 与诊断快照。交付完整的线性域分块降噪引擎：按设备档位规划 16 像素对齐的重叠分块规格（标准档 448×448 / 低端档 256×256，重叠 64 px，末列回退保证定长），执行精确线性 sRGB 与线性 Rec.2020 双向色域转换、半精度浮点张量与夹取后的 ISO 条件输入编解码、源域 `HighlightHeadroomGuard` 高光余量平滑保护（高于 1.0 的线性高光逐像素保留而不被模型硬截断）、强度线性混合、`AutoHighIsoGate` 高感门槛判据及重叠带求和恒为 1 的双线性融合权重；通过进程单活互斥推理会话串行执行，支持逐块进度回报、协作取消与内存不足恢复释放。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

**Acceptance criteria:**

- [ ] 按需模型目录新增 TreeNet Light 四镜像条目，目录校验脚本支持四镜像且单测锁定两侧清单一致，第三方许可声明与实测基线文档同步落盘。
- [ ] 编辑器设置新增直出模式、高感门槛与强度三个键（默认高感自动、ISO 1600、强度 70），单测覆盖默认值、越界 clamp 与跨门面键集合严格互斥。
- [ ] 数值单测锁定线性 sRGB 与 Rec.2020 往返误差达标、半精度张量与 ISO 条件夹取正确、`HighlightHeadroomGuard` 在高光余量区逐字节保真、强度 0 全图恒等及双线性重叠权重在双块与四块交汇处求和恒为 1。
- [ ] 分块规划、高感门槛判据与引擎执行单测覆盖标准/低端档块数、进度单调递增、逐块取消响应、签名不兼容拒绝与 OOM 释放会话恢复。
