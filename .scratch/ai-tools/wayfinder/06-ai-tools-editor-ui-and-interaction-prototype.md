## Question

在不破坏现有单屏 XML/ViewBinding 编辑器信息架构与手势契约（双指在一切工具下强制优先缩放平移画布、单指工具交互与长按 Before/After 原图对比）的前提下，通过低成本可交互原型验证以下体验与交互细节：

1. **工具入口与底栏组织**：编辑器底栏如何收纳「主体（抠图/换底/虚化/前后景调色）」「消除（涂抹画笔/橡皮/笔刷大小/最大面积提示）」「天空（天空选择/边缘与色彩融合）」「云端（默认关闭、开启后可见的 AI 增强入口）」而不造成底栏过载？
2. **异步端侧推理交互态**：主体分割或局部消除耗时 1–5 秒期间的画布反馈、可取消机制、低端机自动降档提示，以及消除笔刷松手即推理 vs 点击“确认消除”触发的交互节奏选择。
3. **模型下载与管理体验**：首次使用需下载模型时的弹窗/内联进度条（含体积提示、Wi-Fi 提醒、多镜像失败后切本地导入引导）以及设置中的统一模型管理页（显示占用空间、单独删除、重下）。

## Answer

可交互原型资产见 [`.scratch/ai-tools/prototype-ai-tools-interaction.html`](../prototype-ai-tools-interaction.html)（含暗房编辑器 390×800 模拟画布、可涂抹 Canvas、双指优先让路、4 个引导走查场景与状态机观测）。锁定交互规范如下：

1. **7 Tab 一级收纳与纯离线洁净度**：
   - `activity_editor.xml` Tier 3 从 6 Tab 扩展为 7 等宽 Tab：`预设 | 几何 | 影调 | 色彩 | 细节 | 人像 | AI`（横屏维持右侧 `320dp` 抽屉）。
   - 点入「AI」后，Tier 2 横向子工具 Chip 收纳 `主体 | 消除 | 天空`；**P4 云端总开关默认关闭，关闭状态下「云端」子工具完全隐藏**，仅在用户主动开启后显示。
   - 子工具启用非默认效果时，在对应 Chip 上显示琥珀色修改圆点（与现有修改指示对齐）。
2. **主体 / 消除 / 天空 / 云端 Tier 1 面板与手势契约**：
   - **主体**：顶部模式 Chip（原背景 / 透明去背 / 纯色换底 + 预设色块），下方 3 条滑杆（背景虚化、前景曝光/色温/饱和度、背景曝光/色温/饱和度）；首次切到非「原背景」或拖动滑杆时按需触发 MODNet 推理。
   - **消除**：采用**「多笔涂抹 + 橡皮修边 → 点击『确认消除』触发推理」**节奏，避免 1.5–5 s 端侧 CPU 推理因单笔误触反复阻塞；保留笔刷大小滑杆与「清空笔迹」按钮。
   - **双指绝对优先**：延续既有手势仲裁契约，任何时刻检测到第二指触碰立即中止并丢弃未完成的单指画笔笔迹、切入画布缩放平移。
   - **面积超限提示**：实时估算涂抹区在源图上的外接框，超过 256×256 px 推荐上限时顶部胶囊给出非阻断琥珀色警告（「建议分次小面积涂抹，或点击确认由后台 256 px 切块消除」）。
3. **1–5 秒异步推理与几何冲突守卫**：
   - 推理进行时在底栏顶部展开非阻塞进度条（显示当前模型名称、进度与「取消」按钮），取消后立即中止作业并保留当前涂抹笔迹与原 `EditGraph`。
   - 低端机（≤4 GB RAM）推理完成后即刻释放 `OrtSession` 并在必要降档时给出轻量胶囊提示。
   - 当照片存在 `CloudEditLayer` 时，用户尝试修改 Pass A 几何（裁剪/旋转/透视/液化）弹出非破坏性确认底单（移除云端层以应用新几何 vs 取消几何改动）。
4. **按需下载、多镜像回退与模型管理**：
   - 首次触发未下载模型时弹出底部确认单：标明模型名称、精确 MB 体积、许可与断点续传能力，并列提供「开始下载」与「导入本地 `.onnx`」。
   - 主源（GitHub Releases）与备用镜像均失败时保留 `.part` 断点文件并显式引导通过系统 SAF 选择器导入本地 `.onnx`（强制 SHA-256 校验）。
   - 应用设置页提供统一「AI 模型管理」页（展示已占空间、各模型状态、单模型删除/重下与「经典天空分割 0 MB 始终可用」说明），删除模型不影响已保存的编辑结果。
